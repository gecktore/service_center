# Сервисный центр

Консольное приложение на Python для управления сервисным центром по ремонту техники.

Приложение позволяет управлять мастерами, создавать и обрабатывать заявки на ремонт, контролировать их статусы, назначать исполнителей и проверяющих, а также сохранять данные в JSON-файл.

## Возможности

### Управление мастерами
- добавление мастеров;
- проверка уникальности телефонных номеров;
- определение уровня мастера;
- учёт начислений и формирование рейтинга.

### Управление заявками
- создание заявок на платный ремонт;
- создание заявок на гарантийный ремонт;
- создание заявок на диагностику;
- просмотр списка заявок;
- поиск заявок по описанию устройства;
- изменение параметров заявок.

### Контроль выполнения работ
- назначение исполнителей;
- назначение проверяющих;
- контроль статусов заявок;
- возврат ремонта на доработку;
- установка зависимостей между заявками;
- проверка ограничений нагрузки мастеров.

### Отчётность
- сводка заявок по статусам;
- подсчёт заявок по видам;
- расчёт ожидаемой выручки;
- рейтинг мастеров по начислениям.

### Хранение данных
- сохранение данных в формате JSON;
- автоматическая загрузка данных при запуске;
- создание пустого сервисного центра, если файл данных отсутствует;
- проверка корректности загружаемых данных;
- обработка ошибок хранения.

## Требования

- Python 3.11 или новее.
- Сторонние библиотеки не нужны — проект использует только стандартную библиотеку Python.

## Структура проекта

```text
.
├── service_center/
```

## Установка и запуск

1. Откройте терминал (например, PowerShell).
2. Перейдите в корневую папку проекта — ту, где находится папка `service_center`:

   ```powershell
   cd "путь\к\проекту"
   ```

3. Запустите приложение:

   ```powershell
   python -m service_center
   ```

После запуска появится главное меню:

```text
=== Сервисный центр ===

1. Мастера
2. Заявки
3. Поиск заявок
4. Сводка
5. Рейтинг мастеров
0. Выход
```

Введите номер нужного пункта и следуйте инструкциям программы.

## Хранение данных

Данные сохраняются в JSON-файл `data/service_center.json`.

- Если файла нет, приложение создаёт новый пустой сервисный центр.
- При штатном выходе данные сохраняются автоматически.
- При следующем запуске сохранённые данные загружаются из файла.

## Обработка ошибок

В проекте предусмотрены собственные исключения:

| Исключение          | Назначение                                |
|---------------------|-------------------------------------------|
| `ValidationError`   | ошибки проверки входных данных            |
| `NotFoundError`     | объект не найден                          |
| `BusinessRuleError` | нарушение бизнес-правил                   |
| `StorageError`      | ошибки сохранения и загрузки данных       |
